# 🎓 Smart Circular AI
**NLP-Based Intelligent College Circular Understanding and Conversational Chatbot with Voice Response**

Upload a college circular (PDF, scanned image, DOCX or TXT) and chat with it in plain English. The system extracts the key facts, understands the question's intent, retrieves the right passage with semantic search (RAG), answers grounded in the real circular, remembers the conversation, and can read the answer aloud with gTTS.

| Layer | Technology |
|---|---|
| Frontend | React 18 + Vite, React Router (dark/light theme, voice input) |
| Backend | Python + FastAPI (REST) |
| NLP | Regex/rule-based NER, sentence segmentation, tokenisation, TF-IDF + Logistic Regression intent classifier, extractive summariser (spaCy optional) |
| Embeddings / Vector DB | Sentence-Transformers (MiniLM) + FAISS — auto-falls back to TF-IDF cosine |
| RAG / LLM | Retrieval-Augmented Generation with Gemini (REST). Works fully offline without a key |
| PDF / OCR | PyMuPDF, Tesseract or EasyOCR |
| Database | SQLite (circulars, chunks, chat history) |
| Voice | gTTS (answers) + browser Web Speech API (mic input) |

## ✨ Features
- **Key-fact cards** – date, time, venue, deadline (with live countdown), eligibility, department, contact
- **Intent detection** – date / time / location / eligibility / deadline / registration / contact / instructions / fee / summary
- **Conversation memory** – "When is the training?" → "Where?" → "What's the last date?" stays on the same circular
- **Multi-circular chat** – pick one, or let the AI auto-detect which circular a question is about
- **Explainable answers** – intent, confidence meter, engine badge and the evidence / retrieved chunks behind each answer
- **Voice** – 🔊 Listen button (gTTS), auto-speak toggle, 🎤 mic input
- **History** – searchable Q&A log grouped by circular, "Ask again"
- **Out-of-scope guard** – says *"I couldn't find that in the circular"* instead of guessing
- **Scanned circulars** – automatic OCR fallback for image PDFs and photos

## 🚀 Quick start

**Prerequisites:** Python 3.10+, Node.js 18+

### 1) Backend
```bash
cd backend
python -m venv venv
# Windows: venv\Scripts\activate      Mac/Linux: source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # (optional) add GEMINI_API_KEY
uvicorn app.main:app --reload --port 8000
```
> First run downloads the MiniLM model (~90 MB). To skip it: set `EMBEDDINGS=tfidf` in `.env`.
> Lighter install: remove `sentence-transformers` and `faiss-cpu` from requirements.txt — the app switches to TF-IDF automatically.

### 2) Frontend (new terminal)
```bash
cd frontend
npm install
npm run dev
```
Open **http://localhost:5173** → *Circulars* → **Load sample circulars** → *Chatbot*.

Shortcut: `./start.sh` (Mac/Linux) or `start.bat` (Windows) after installing dependencies once.

### Single-server mode
```bash
cd frontend && npm run build        # creates frontend/dist
cd ../backend && uvicorn app.main:app --port 8000     # serves UI + API at http://localhost:8000
```

## 🔑 Gemini (optional but recommended for the demo)
Get a free key at https://aistudio.google.com/apikey and put it in `backend/.env`:
```
GEMINI_API_KEY=your_key
```
With a key, answers are generated by Gemini using the retrieved circular text (RAG) and the NLP-extracted facts; without it the built-in extractive NLP engine answers.

## 🔎 OCR (scanned notices)
- Tesseract: install the engine (Windows: https://github.com/UB-Mannheim/tesseract/wiki, Ubuntu: `sudo apt install tesseract-ocr`) — `pytesseract` is in requirements.
- or EasyOCR: `pip install easyocr` (no system install, bigger download).

## 🧠 How a question is answered
```
Question ─▶ follow-up resolution (memory) ─▶ intent classification (rules + TF-IDF/LogReg)
        ─▶ semantic retrieval (MiniLM+FAISS ⊕ TF-IDF) ─▶ pick circular (similarity + title match + topic stickiness)
        ─▶ fact-grounded extractive answer ─▶ Gemini RAG rewrite (if key) ─▶ confidence score ─▶ gTTS
```

## 🌐 REST API
| Method | Endpoint | Purpose |
|---|---|---|
| POST | `/api/circulars` | upload + process a circular (multipart `file`) |
| GET | `/api/circulars` · `/api/circulars/{id}` | list / details (facts, summary, entities) |
| DELETE | `/api/circulars/{id}` | delete |
| POST | `/api/circulars/samples/load` | load demo circulars |
| POST | `/api/chat` | `{question, session_id, circular_id?}` → answer, intent, confidence, sources, suggestions |
| GET / DELETE | `/api/history/{session_id}` | chat history |
| GET | `/api/tts/{message_id}` | MP3 of an answer (gTTS) |
| GET | `/api/stats` | counters + which engines are active |

Interactive docs: http://localhost:8000/docs

## 📝 Notes
- gTTS and Gemini need internet access; everything else runs offline.
- RAG is implemented directly (embeddings → FAISS → prompt) rather than through LangChain, which keeps the pipeline transparent and dependency-light; the retriever/LLM modules are easy to wrap in LangChain if your syllabus requires it.
- Voice input uses the browser's Web Speech API (Chrome / Edge).
